1. ОПИСАНИЕ ПРОЕКТА
--------------------------------------------------------------------------------
Проект реализует систему автономного технического зрения для БПЛА.
Задача: попиксельная классификация поверхности и препятствий (12 классов) 
на снимках 256x256 пикселей.

Особенность реализации:
Автоматический подбор оптимальной архитектуры сверточной нейросети U-Net 
(глубина, количество каналов) и скорости обучения (Learning Rate) с помощью 
математического фреймворка глобальной оптимизации iOpt (ННГУ им. Лобачевского).

4. ТРЕБОВАНИЯ И БЫСТРЫЙ СТАРТ
--------------------------------------------------------------------------------
Рекомендуемая версия: Python 3.10 или 3.11 (тестирование работоспособности проводилось на версии 3.11.6).

Шаг 1. Создание и активация окружения:
	python -m venv venv
	.\venv\Scripts\Activate.ps1       (Windows PowerShell)
	source venv/bin/activate          (Linux / macOS)

Шаг 2. Обновление pip до актуальной версии:
	python -m pip install --upgrade pip

Шаг 3. Установка PyTorch с поддержкой GPU CUDA:
	pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121 --default-timeout=1000

Шаг 4. Установка совместимого NumPy (строго версия < 2.0 для работы iOpt):
	pip install "numpy<2"

Шаг 5. Установка остальных библиотек:
	pip install pandas seaborn opencv-python albumentations matplotlib tqdm scikit-learn torchmetrics iopt

Шаг 6. Запуск процесса оптимизации и обучения:
	python drone_notebook.py

5. КЛЮЧЕВЫЕ ПАРАМЕТРЫ (КОНФИГУРАЦИЯ В КОДЕ)
--------------------------------------------------------------------------------
Все настройки задаются в секции "# Параметры" файла drone_notebook.py:

* BATCH_SIZE = 16				- Размер пакета данных (зафиксирован для защиты VRAM);
* IMAGE_SIZE = 256				- Разрешение входного тензора сети;
* ITERS_LIMIT = 200				- Число итераций глобального поиска iOpt;
* EPOCHS_FOR_OPT = 10			- Длительность пробного обучения при оптимизации;
* R_OPT = 4.0					- Коэффициент надежности метода iOpt (поиск глобального минимума);
* EPOCHS_FOR_TRAIN = 200		- Число эпох полного обучения найденной лучшей модели;

Пространство оптимизации iOpt:
- log10_learning_rate			: непрерывный от -4.0 до -2.0 (LR от 0.0001 до 0.01);
- base_nc						: дискретный ["16", "32", "64", "128"] (базовые каналы);
- num_downs						: дискретный ["4", "5", "6", "7"] (глубина блоков U-Net).

6. ПАЙПЛАЙН РАБОТЫ СКРИПТА
--------------------------------------------------------------------------------
1. ПОДГОТОВКА:
	Чтение файлов, конвертация RGB-масок в целочисленные индексы, аугментация.
	Разбиение выборки: 70% Train / 20% Val / 10% Test.

2. ОПТИМИЗАЦИЯ (iOpt):
	Поиск минимума Validation Loss с защитой от расходимости (NaN Loss = штраф 999.0).
	Результат сохраняется в checkpoints/best_iopt_params.json.

3. ОСНОВНОЕ ОБУЧЕНИЕ:
	Инициализация модели с лучшими параметрами и обучение на 200 эпох.
	Каждая эпоха сохраняется в каталог checkpoints/epochs/.
	Абсолютно лучшая модель сохраняется в checkpoints/MODEL_BEST.pth.

4. ТЕСТИРОВАНИЕ:
	Расчет итоговых метрик на тестовой выборке:
		- Общая точность (Pixel Accuracy);
		- Средний индекс Жаккара (mIoU);
		- F1-Score (Dice) по каждому классу;
		- Построение тепловой карты матрицы ошибок (Confusion Matrix);
		- Визуализация предсказания маски на примере тестового кадра.
